# ms-file-transfer-api

**Version**: 1.2.6

The Editor Connection Microservice File Transfer API (`ms-file-transfer-api`) is a microservice designed for seamless file transfers between Google Drive and AWS S3. This service manages uploading and downloading files, with a robust logging system that stores logs either locally (for development) or in an S3 bucket (for production).
